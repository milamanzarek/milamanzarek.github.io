## The challenge

The nonprofit was producing valuable content, but publishing it was a major operational bottleneck: manual page updates, version control issues, and delays that distracted a small team from mission work.

## What I did

* Built a custom content management system using Microsoft SharePoint as the database and Power Automate to orchestrate publishing workflows.
* Connected the pipeline to the public website via API so approved content publishes in real time.

## Results

* Real-time site updates with no manual publishing step.
* A scalable system a volunteer-scale team can operate, with governance appropriate for a 501(c)(3).

**Stack:** SharePoint, Power Automate, API pipeline.
