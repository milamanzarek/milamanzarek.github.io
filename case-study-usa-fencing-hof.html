Case Study 05 / USA Fencing Hall of Fame

From inherited mess to transparent Hall of Fame governance.

As Chair of the USA Fencing Hall of Fame Committee, I turned scattered history, criteria, rubrics, and review decisions into a structured public governance system with a review portal, database-backed scoring rules, and automated ballot infrastructure.

Chair-led governance Mermaid data model Neon database Node.js pipeline Netlify portal Public ballot system
Narrative

Governance work needs structure, not heroics.

My onboarding as Chair was one sentence: "Congratulations, you inherited a mess." The committee process carried real institutional weight, but the operating layer around it was too manual for a sensitive Hall of Fame election.

I led the governance process and built the system behind it: data modeling, rubric rules, nominee records, committee review views, and ballot generation. The result was not just a website. It was a transparent operating system for a trust-sensitive decision process.

Transparency is the product.

Committee Review Portal

The public-facing review layer gives committee members structured context: category, eligibility, prior ballot status, source links, background, and scoring logic.

Structured Nominee Record

Nominee history, category, ballot pathway, scoring method, flags, and key credentials were moved into structured source data instead of loose narrative fragments.

Rendered Nominee Profile

The structured nominee record becomes a review-ready frontend card, giving committee members consistent context instead of disconnected notes.

Rubric Rules Database

Criteria were operationalized as data: event keys, point values, descriptions, achievements, and rubric relationships inside Neon.

Ballot Build Logic

Category caps, profile styling, and ballot rendering rules were encoded in the build pipeline so outputs stayed consistent.

Database-Backed Governance Layer

The review process became auditable infrastructure, connecting rubric rules, nominee records, achievement logic, committee review, and ballot output.
